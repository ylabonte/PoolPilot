# PoolPilot

**PoolPilot** is a native iOS and Android app for monitoring and controlling your pool — driving
both the **ProCon.IP** and **VIOLET** pool controllers from a single app.

🌐 **[poolpilot.eu](https://poolpilot.eu)** — website, downloads, and help.

## Report a bug · request a feature · ask a question

This repository is PoolPilot's public **issue tracker**. Please
[open an issue](../../issues/new/choose) and pick the matching template.

Looking for help first? See **[poolpilot.eu/support](https://poolpilot.eu/de/support)**.
