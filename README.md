# PoolPilot

**PoolPilot** is a native iOS and Android app for monitoring and controlling your pool —
one app for both the **ProCon.IP** and **VIOLET** pool controllers.

- 🌐 **Website & help:** [poolpilot.eu](https://poolpilot.eu)
- 🔌 **PoolPilot Relay** — secure remote access & push for the ProCon.IP:
  [ylabonte/poolpilot-relay](https://github.com/ylabonte/poolpilot-relay)

## Report a bug · request a feature · ask a question

This repository is PoolPilot's public **issue tracker**. Please
[open an issue](../../issues/new/choose) and pick the matching template.

Looking for help first? The **[Help & FAQ](https://poolpilot.eu/de/support/)** already
answers many common setup and connection questions.

> ⚠️ Issues here are public — please don't post credentials or IP addresses.

## Security

Found a security issue? Please report it **privately** — see
**[SECURITY.md](.github/SECURITY.md)**, not a public issue.
